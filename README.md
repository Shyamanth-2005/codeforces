# Codeforces Solutions

This repository contains my solutions to various Codeforces programming problems. Each problem is solved in Python and follows a consistent structure.

## 📁 Repository Structure

```
codeforces/
├── README.md
└── [problem_id]_[problem_name].py
```

## 🚀 How to Use

Each Python file corresponds to a specific Codeforces problem and can be run independently:

```bash
python [problem_id]_[problem_name].py
```

## 📝 Problem Categories

The solutions cover various difficulty levels and topics including:

- **Beginner (A problems)**: Basic algorithms, string manipulation, mathematics
- **Implementation**: Simple logic and data structure operations
- **Mathematics**: Number theory, arithmetic operations
- **Strings**: Pattern matching, transformations
- **Arrays**: Basic array operations and algorithms

# Codeforces Solutions

This repository contains my solutions to various Codeforces programming problems. Each problem is solved in Python and follows a consistent structure. The solutions are organized by problem ID and name, making it easy to find specific problems.

## 📁 Repository Structure

```
codeforces/
├── README.md
├── LICENSE
└── [problem_id]_[problem_name].py
```

## 🚀 How to Use

Each Python file corresponds to a specific Codeforces problem and can be run independently:

```bash
python [problem_id]_[problem_name].py
```

Most solutions read from standard input and write to standard output, following Codeforces' standard I/O format.

## 📝 Problem Categories

The solutions cover various difficulty levels and topics including:

### Beginner Problems (Division 4 & A problems)
- Basic algorithms and implementation
- Simple mathematical operations
- String manipulation
- Array operations

### Intermediate Problems (B-C problems)
- More complex algorithms
- Data structures usage
- Advanced mathematical concepts
- Dynamic programming basics

### Topics Covered
- **Mathematics**: Number theory, arithmetic operations, combinatorics
- **Strings**: Pattern matching, transformations, parsing
- **Arrays**: Sorting, searching, basic operations
- **Implementation**: Simulation, brute force approaches
- **Greedy Algorithms**: Optimization problems
- **Basic Graph Theory**: Simple graph problems
- **Sorting & Searching**: Binary search, sorting algorithms
